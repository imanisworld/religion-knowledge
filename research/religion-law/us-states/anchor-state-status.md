# Anchor-State Status

All eight priority anchor states now have a verified first-pass legal baseline:

- Maryland — current religious-test text + *Torcaso* enforceability.
- Arkansas — anti-evolution law + *Epperson*.
- Louisiana — Balanced Treatment Act + *Edwards*; official code still flags unconstitutionality.
- Connecticut — contraception restriction + *Griswold*; religion-causation analysis remains open.
- Texas — Article I, §4 + Penal Code §21.06 + *Lawrence*.
- Montana — no-aid clause + *Espinoza*.
- Maine — *Carson*, repeal of the nonsectarian condition in 2025, and current Sunday vehicle-sales restriction.
- Massachusetts — *Goodridge* and current same-sex-marriage legal baseline.

These are anchor baselines, not complete state profiles. Broader constitutional provisions, accommodations, current statutes, and historical-causation claims still require state-specific review.

A landmark case alone does not make a state profile complete. Current text, enforceability, and historical causation remain separate fields.
